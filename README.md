# 🔧 WMotorPro – Sistema de Gestión para Talleres Mecánicos

## 📌 Sobre el proyecto

WMotorPro es una aplicación web desarrollada como proyecto final de mi formación en Desarrollo de Software.

Su objetivo es facilitar la administración y organización de un taller mecánico, reuniendo en un mismo sistema las principales tareas de gestión.

## ⚙️ ¿Qué permite hacer?

- **Gestión de clientes:** registrar y consultar información de los clientes.
- **Gestión de empleados:** administrar los empleados del taller.
- **Turnos:** organizar y gestionar las citas de los clientes.
- **Órdenes de trabajo:** registrar y realizar el seguimiento de los trabajos del taller.
- **Repuestos y stock:** administrar los repuestos y controlar las existencias.
- **Facturación y pagos:** gestionar las facturas y los pagos.
- **Panel de control:** consultar información general y estadísticas del taller.
- **Usuarios y permisos:** acceso según los distintos roles del sistema.

## 💻 Tecnologías utilizadas

- Java
- Spring Boot
- Angular
- MySQL
- Git

## 🎯 Objetivo del proyecto

Poner en práctica los conocimientos adquiridos durante mi formación, desarrollando una solución que permita organizar y facilitar las tareas habituales de un taller mecánico.
